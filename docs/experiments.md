# 实验与评测规范

> 状态：评测计划，所有结果待运行。来源为[完整技术设计](technical-design.md)第 1、8–11、14、17 节；统计与日志细则为实施建议。

## 假设与证据对应

| 假设 | 主实验 | 必须排除的解释 |
| --- | --- | --- |
| H1 可解码 | 不同长度与步长的自编码；关闭、置零、打乱、替换矩阵 | Decoder 只利用输出 Token 历史 |
| H2 可生成 | 从输入独立采样块并解码；对比教师潜在状态 | 验证时使用目标答案或目标 latent |
| H3 可编辑 | 同一待修复状态上的 EDIT、无 EDIT 与额外 APPEND | 更多计算本身带来提升；只降低 latent MSE |
| H4 资源自适应 | 预算扫描；固定策略与学习控制器对比 | 靠无限追加或更大预算提升准确率 |
| H5 详略控制 | 固定同一 `M_final`，改变步长、详细度与长度上限 | 篇幅增长仅来自重复，或核心结论发生变化 |

H3 应同时测“给定正确编辑位置”和“控制器自主定位”，分开判断修复器与位置选择的贡献。H4 对不同预算报告质量—成本曲线，不能仅展示单个最有利配置。

## 对照与消融

| 编号 | 设置 | 研究问题 |
| --- | --- | --- |
| A0 | 纯 AR，匹配计算预算 | 相比常规生成是否有收益 |
| A1 | Latent Encoder + AR Decoder，无 Diffusion | 潜在矩阵能否被有效读取 |
| A2 | 固定长度潜在 Diffusion | 动态增长是否必要 |
| A3 | 只允许 APPEND | EDIT 的额外作用 |
| A4 | APPEND + EDIT，无全局概要 | 全局概要对一致性的作用 |
| A5 | APPEND + EDIT + STOP | 学习停止与固定预算的差异 |
| A6 | 整矩阵 Decoder 与 64 槽窗口 | 局部读取的质量和效率代价 |
| A7 | `r=8/16/32/64` | 步长对覆盖、详略和正确性的影响 |
| A8 | 自适应 ADVANCE 与固定周期推进 | 学习推进是否改善信息覆盖 |
| A9 | DDPM 与 Flow Matching | 质量、采样步数与成本的差异 |
| A10 | 仅答案／推理轨迹／混合潜在目标 | 内部工作空间应表达什么 |
| A11 | 冻结／部分共享／端到端 | 接口稳定性与联合调整的取舍 |

A4/A5 是原稿的实验标签，不能直接把两行差值都归因于 STOP。实际运行时应分别建立单变量对照：开关全局概要时固定动作集合；开关学习 STOP 时固定概要、采样器、最大预算和其他组件。每个 A 编号都需落到完整配置。

建议先完成 S1 的 A0/A1/A2/A3/A9 与最小修复验证，再进入 S2 完整控制器和输出控制。此顺序是节约试验成本的建议，不是已有进展。

## 公平预算

所有关键对比尽量匹配训练样本、训练 FLOPs 和推理 FLOPs；参数量单独接近不足以证明公平。不能精确匹配时，公开差额并提供预算扫描。统一 tokenizer、测试集、硬件、数值精度、batch size、输出上限及校验规则，或明确记录差异。

对每个答案记录实际 APPEND/EDIT 次数与采样步数：

$$
N_{denoiser\_forwards}=\sum_{i\in\mathrm{APPEND,EDIT}} T_i.
$$

若所有更新均使用固定 `T`，则为 `N_update_ops * T`。控制器 STOP 检查不包含去噪前向；原稿的 `N_outer_ops * T` 是粗略估计。8 次实际更新且每次 16 步对应 128 次去噪前向，仍不含 Encoder、控制器、检索和 AR Decoder。

记录训练与推理的实际成本，而非把去噪前向次数等同于 FLOPs。端到端延迟应覆盖输入编码到最后一个输出 Token；另报内部推理、解码阶段的分项延迟。GPU 测量需同步，区分预热和正式采样，并记录是否包含数据加载和主机传输。

## 必报指标与定义

| 类别 | 指标 | 口径 |
| --- | --- | --- |
| 正确性 | 任务准确率／程序校验率 | 正确样本数除以全部评测样本数；失败与预算终止计入分母 |
| 泛化 | OOD 准确率 | 按任务、依赖深度或组合类型分层报告 |
| 修复 | 配对准确率差 | 同一批状态修复后准确率减去修复前准确率 |
| 修复 | 错误恢复率 | 初始错误且修复后正确的样本数／初始错误样本数 |
| 修复 | 正确破坏率 | 初始正确但修复后错误的样本数／初始正确样本数 |
| 成本 | 延迟、FLOPs、吞吐、显存峰值 | 给出设备、测量边界、精度和 batch；建议延迟同时报中位数与 P95 |
| 状态 | 最终块数、追加／修改次数、去噪前向数 | 报均值与分布；分开记录主动 STOP 与预算强制终止 |
| 输出 | Token 数、事实覆盖、重复率 | 固定 tokenizer 与事实／重复判定方式；人工评审说明抽样与标注方式 |
| 窗口 | 访问数、移动数、覆盖率 | 访问数包括首次窗口；移动数不包括首次读取；覆盖率为读过的不同有效槽数／有效槽数 |
| 一致性 | 跨窗口与跨详略一致性 | 对比同一矩阵的核心事实和结论；明确自动或人工判定方法 |
| 稳健性 | 扰动修复率、预算敏感性、长输入失败 | 给出扰动类型和难度分层，保留失败例 |

分母为零时记录“不适用”，不能记为 0% 或 100%。潜在 MSE、重构交叉熵为过程指标，不能代替最终答案指标。不要在同一张表中混合教师潜在条件与自主生成结果而不标记。

## 统计与停止规则

S1/S2 使用多个训练随机种子，报告每次运行与跨种子均值、置信区间；实施上建议先以至少 3 个种子估计方差，关键结论按预算和统计功效增加复制。该数量是建议，原稿未指定固定个数。

同一测试集上的模型对比优先保留逐样本配对结果，使用适合任务的配对检验或配对 bootstrap。需区分“评测样本不确定性”和“训练种子波动”，写明区间估计方法。提前选定主指标、成本上限、最小有意义收益、失败标准及检验规则；这些数值目前待定，不能在看到测试结果后再为结论调阈值。

验证集用于选超参数、检查点和推理预算；测试集用于最终报告。探索性消融与确认性对照应分别标记。S4/S5 的单次探索不作为可重复收益的证据。
