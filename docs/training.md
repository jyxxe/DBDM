# 分阶段训练

> 状态：训练计划，未提供可运行训练入口或完成结果。来源为[完整技术设计](technical-design.md)第 4、6–7、9 节；以下检查项为落地建议。

## 数据与隔离

保留三类监督：`(x, y)`、`(x, reasoning, y)`、`(x, structured_state, y)`。早期采用程序可校验的整数运算、图任务、逻辑约束、表格计算或程序执行；文本阶段加入同问题的简略／标准／详细配对答案。

训练、验证、测试应按模板组合、操作深度、图结构、数字长度与随机种子隔离。OOD 测试需要新的组合或更长依赖，不能只更换样本种子。对每份数据记录版本、生成器提交、划分规则、去重策略与校验器版本。

| 数据类型 | 建议记录字段 | 用途 |
| --- | --- | --- |
| 基本任务 | 样本 ID、输入、答案、任务类别、难度、划分、数据版本 | 条件生成和准确率评测 |
| 潜在目标 | 编码器 checkpoint、归一化版本、块数、有效 mask、目标类型 | 阶段 2 的冻结监督 |
| 修复样本 | 原始状态、损坏状态、损坏类型、修复区间、正确答案 | 区分内容修复与随机去噪 |
| 操作轨迹 | 每步前状态、动作、位置、剩余预算、反馈 | 控制器与位置头训练 |
| 详略配对 | 同一输入的多个详细度答案、核心事实、长度约束 | 输出控制和一致性 |

上述字段是概念要求，实际序列化 schema 在实现时定义。

## 训练顺序与阶段门槛

| 阶段 | 主要训练对象 | 目标与数据流 | 阶段证据 |
| --- | --- | --- | --- |
| 0 数据与基线 | 标准 AR 基线 | 建立数据、校验器与计算测量 | 可复现划分和基线记录 |
| 1A 自编码 | `E_lat + AR Decoder` | `y -> Z* -> 64 槽窗口 -> y` | 重构质量及矩阵依赖对照 |
| 1B 输入表示 | `E_in` | 从 `x` 学习输入理解与条件辅助目标 | 验证期无答案输入旁路 |
| 1C 接口对齐 | 按需联合或部分冻结 | 固定潜在接口，训练长度、窗口与详略条件 | 潜在分布和输出控制稳定 |
| 2A 条件生成 | 块 Diffusion / Flow | 用冻结的 `E_lat` 产生监督；从 `C` 生成新块 | 无目标答案访问的采样可解码 |
| 2B 修复 | 块更新器及修复条件模块 | 从损坏状态学习恢复正确任务状态 | 最终答案改善，含负向案例 |
| 2C 策略 | 操作控制器与位置头 | APPEND/EDIT/STOP 与位置监督；后续加入可验证奖励 | 预算与停止行为校准 |
| 3 有限联合调整 | 选择性解冻部分模块 | 小学习率优化终端指标，约束潜在漂移 | 不破坏已验证接口与收益 |

阶段 1A 是重构实验，允许 `E_lat` 读取 `y`；它不能用作“输入到答案的条件生成已成功”的证据。阶段 2 的参考方案冻结定义潜在空间的模块；如解冻 Decoder 或 Encoder，需单独记录并重新确认缓存与目标分布。

## 关键训练目标

阶段 1A 的局部窗口重构：

$$
\mathcal L_{recon}=-\sum_t\log p(y_t\mid y_{<t},W_{j(t)},v,r).
$$

建议加入潜在归一化、少量噪声鲁棒性、块遮蔽、位置编码和窗口覆盖约束。必须做矩阵关闭、置零、打乱、跨样本替换等反事实对照；仅有低交叉熵不足以排除 Decoder 忽略潜在信息。

阶段 2A 的目标编码：

$$
Z^*=\operatorname{StopGrad}(E_{lat}(y)).
$$

一次采样一个目标块和一个噪声时刻训练，无需每个样本都反向展开全部采样轨迹。先验证单块条件生成，再扩展多块 APPEND。训练可用真实前序块作为教师上下文，但必须与自主生成上下文分别评测，不能把教师条件下的损失当作闭环推理质量。

综合损失按阶段启用：

$$
\mathcal L=\lambda_r\mathcal L_{recon}+\lambda_d\mathcal L_{diff/FM}
+\lambda_a\mathcal L_{action}+\lambda_s\mathcal L_{span}
+\lambda_e\mathcal L_{edit}+\lambda_c\mathcal L_{consistency}
+\lambda_b\mathcal L_{budget}.
$$

| 项目 | 训练注意事项 |
| --- | --- |
| 重构损失 | 同时看自由解码和矩阵依赖，防止只靠 Token 历史 |
| 生成损失 | 记录 latent MSE 与最终答案，二者不能互相替代 |
| 动作与位置损失 | 保存标签生成规则；对非法动作做状态相关 mask |
| 修复损失 | 包含语义错误和模型采样错误，不能只用高斯扰动 |
| 一致性损失 | 判别器或验证器本身需要独立校验 |
| 预算损失 | 记录系数与实际成本，检查是否造成过早 STOP |

损失权重、归一化方式和调度未在原稿中定值，应作为配置和实验变量记录。

## 防止目标泄漏

1. 正常推理入口只接收 `x` 和预算／输出控制，不接收 `y`、`E_lat(y)` 或目标块数。若使用预测块数，必须从输入或当前状态得到。
2. `E_lat(y)` 只走监督路径。评测重构、教师条件生成、自主生成三种模式时分别命名和汇报。
3. 训练控制器时，真实答案或校验器可产生离线标签／奖励；不能把它们作为部署时不存在的即时输入。
4. latent 缓存绑定目标编码器、tokenizer、归一化与数据版本；编码器改变后应重算或显式判作不兼容。
5. 跨样本矩阵替换、窗口 mask 与 padding 测试应检查 batch 边界，避免读到其他样本的信息。

## 断点与复现

保存模型、优化器、学习率调度、随机状态、采样器进度、阶段编号、冻结模块清单、数据版本与配置。阶段切换先保留可复现的前一阶段 checkpoint。潜在归一化统计和 tokenizer 也是 checkpoint 兼容性的一部分。
