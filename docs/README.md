# DBDM 文档

DBDM（Dynamic Block Diffusion Model，动态矩阵块扩散推理模型）研究如何在可增长、可重写的连续潜在工作空间中进行推理，再用局部窗口自回归 Decoder 输出文本。

## 核心约定

- 工作矩阵采用 `[batch, slots, channels]`，通道宽度为 `d_z`，通常有 `n = 64K` 个槽；64 槽不等于 64 个 Token。
- `APPEND` 在末尾追加 64 槽；`EDIT` 替换已有的 64 槽区间；`STOP` 结束内部推理。首版 EDIT 建议对齐块边界，后续研究任意连续区间。
- `E_in(x)` 提供输入条件；`E_lat(y)` 定义训练目标潜在空间。正常推理不能访问目标答案 `y` 或其编码。
- 两个 Encoder 同档规模相同，默认不共享权重。输出保留 AR Decoder，潜在 Cross-Attention 每次仅可见 64 槽；输出历史由因果 Self-Attention 读取。
- 建议内部推理结束后固定最终矩阵，再开始文本解码。详略由 `(stride, verbosity, max_output_tokens)` 联合控制，不能把步长等同于输出长度。
- 先验证 S1/S2 的机制和预算匹配收益，再考虑更大规模。所有研究结论必须附带真实计算成本、对照与失败案例。

## 研究问题

| 假设 | 需要证明的行为 |
| --- | --- |
| H1 可解码 | 局部窗口 Decoder 能重构文本，而且确实利用矩阵 |
| H2 可生成 | 不访问目标答案的条件块生成能产生可解码状态 |
| H3 可编辑 | EDIT 改善最终答案，而不只是降低潜在 MSE |
| H4 资源自适应 | 控制器在质量与预算之间作出有效决策 |
| H5 详略控制 | 同一最终矩阵上的不同详略回答保持核心事实一致 |
